# 人格搭子 · 互补匹配系统（可管理版）

一个**自带管理后台**的人格匹配应用。你可以在后台改题目、改人格名称、改文案、看用户数据，改动**全站立即生效**。

## 快速启动

```bash
cd buddy
node server.js
```

- 🌐 前台（用户测试入口）：`http://localhost:3000/`
- 🔐 管理后台：`http://localhost:3000/admin.html`

> 首次启动会在终端打印管理员密码（默认 `admin123`，**登录后请立即在后台修改**）。
> 可用环境变量 `ADMIN_PASSWORD=你的密码 node server.js` 指定初始密码。

## 管理后台功能

| 模块 | 能做什么 |
|------|---------|
| 📊 数据看板 | 累计/今日测试人数、人格分布 TOP10 |
| ❓ 题目管理 | 增删改 30 道题，改维度/方向，恢复默认 |
| 🧬 人格名称 | 改 64 种人格的名称和标签 |
| 📝 文案模板 | 改结果页所有展示文案 |
| 🗂️ 测试记录 | 查看每条记录、按编码搜索、导出 CSV、清空 |
| 🔑 修改密码 | 改管理员密码 |

## 如何让别人也能玩（公网部署）

**方式一：免费托管（推荐，无需买服务器）**

把你的服务器代码部署到任意支持 Node 的平台（如 Render、Railway、Fly.io）：
1. 把 `buddy` 文件夹整个上传
2. 启动命令填：`node server.js`
3. 平台会分配一个公网 https 地址，发给别人即可

**方式二：用云主机/轻量服务器**

把 `buddy` 文件夹上传到服务器，用 PM2 守护运行：
```bash
npm i -g pm2
pm2 start server.js --name buddy
pm2 save
```
然后用 Nginx 反代 3000 端口，绑定你的域名。

**方式三：本机临时分享**

本机运行后，用内网穿透（frp / ngrok / cpolar）把 3000 端口映射到公网，可临时给别人玩（电脑需保持开机）。

## 数据存储位置

所有数据在 `buddy/data/` 目录下：
- `config.json` — 题目、人格、文案（管理后台修改的内容）
- `records.json` — 用户测试记录
- `auth.json` — 管理员密码（加密存储）

**备份 = 复制这个目录**；部署到新环境时带上它即可保留数据。

## 安全提示

- 后台 `/admin.html` 只有密码保护，**务必修改默认密码**
- 记录上报接口未做频率限制，公网部署时建议前面加一层限流/防火墙
- 如需 HTTPS，用部署平台自带证书或 Nginx 配置
